# 🏺 Прованс Декор - Интернет-магазин декора

Современный интернет-магазин товаров для дома и декора, построенный на Next.js 15 с полной системой управления товарами и заказами.

## 🚀 Технологии

- **Frontend**: Next.js 15, React 19, TypeScript
- **Стилизация**: Tailwind CSS 4, Custom CSS
- **База данных**: PostgreSQL + Prisma ORM
- **Аутентификация**: NextAuth.js (Email/Password + OAuth)
- **Состояние**: Redux Toolkit
- **Изображения**: Next.js Image Optimization

## �� Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/AlexQsQ/provans33.git
cd provans33
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения:
```bash
cp .env.example .env.local
```

4. Настройте базу данных:
```bash
npx prisma db push
npx prisma generate
```

5. Запустите проект:
```bash
npm run dev
```

## 🔧 Конфигурация

### База данных
Создайте PostgreSQL базу данных и обновите `DATABASE_URL` в `.env.local`:
```
DATABASE_URL="postgresql://username:password@localhost:5432/provans"
```

### NextAuth
Настройте переменные для аутентификации:
```
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-secret-key
```

## 🐳 Оптимизация Docker образа фронтенда (< 4 GB без S3)

Чтобы образ не превышал лимит хостинга:

1. Включён `output: 'standalone'` в `src/frontend/next.config.ts` — рантайм содержит только минимальный сервер и статические файлы.
2. Многостадийный Dockerfile `src/frontend/Dockerfile`:
	- `deps` (установка зависимостей)
	- `builder` (сборка Next)
	- `proddeps` (чистые прод. зависимости)
	- `runner` (финальный минимальный слой)
3. В корневом `.dockerignore` исключены тяжёлые директории: `archive`, `public-old`, бэкапы, `.next` и т.п.
4. Изображения должны находиться только в `src/frontend/public` (без дубликатов и сырья PSD/RAW). Перед добавлением — сжимать.
5. Не класть большие JSON‑бэкапы в корень (они игнорируются, но лучше держать их вне контекста сборки).
6. При необходимости дополнительного уменьшения: конвертация в WebP (можно добавить скрипт с `sharp`).

Проверка размера итогового образа:
```bash
docker build -f src/frontend/Dockerfile -t provans-frontend:standalone .
docker image inspect provans-frontend:standalone --format='{{.Size}}'
```

Если снова растёт размер:
- удалить неиспользуемые изображения;
- сезонные коллекции хранить вне репозитория до актуальности;
- включить автоматическую оптимизацию (будущий скрипт `npm run images:opt`).

Внешнее хранилище (S3/R2) пока не требуется — текущая стратегия укладывается в лимиты.
